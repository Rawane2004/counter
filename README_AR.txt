ماسح المنتجات - نسخة OCR عربية وإنجليزية باستخدام Python

المتطلبات:
- Python 3.10 إلى 3.12 (يفضل 3.11)
- اتصال إنترنت أول مرة لتحميل نماذج EasyOCR
- Node.js غير مطلوب لتشغيل نسخة OCR الجديدة.

1) افتح مجلد المشروع counter.
2) افتح Terminal داخل المجلد.
3) أنشئ بيئة افتراضية:
   py -3.11 -m venv .venv
   .venv\Scripts\activate
4) ثبّت المكتبات:
   python -m pip install --upgrade pip
   pip install -r backend/requirements.txt
5) شغّل خادم Python من داخل مجلد counter:
   uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
6) افتح واجهة الموقع عبر خادم محلي في Terminal آخر من داخل مجلد counter:
   python -m http.server 5500
7) افتح هذا العنوان في المتصفح:
   http://localhost:5500

مهم:
- يجب أن يبقى خادم Python وخادم الموقع يعملان أثناء الاستخدام.
- أول تشغيل لـ EasyOCR قد يستغرق وقتاً لأنه يحمّل نماذج العربية والإنجليزية.
- الكاميرا تعمل عادة عبر localhost أو HTTPS، وليس بفتح index.html مباشرة.
- يمكن أيضاً اختيار صورة من الجهاز بدلاً من الكاميرا.
- يجب مراجعة السعر والاسم ثم الضغط على «تأكيد وإضافة». لا تتم إضافة المنتج تلقائياً.
- إذا لم يكن السعر ظاهراً على ملصق العبوة، فلا يمكن استخراجه من الصورة. امسح بطاقة الرف أو أدخل السعر يدوياً. جلب السعر عبر الباركود يحتاج لاحقاً إلى ربط قاعدة بيانات منتجات/أسعار.
- هذه نسخة أولى: OCR قد يخطئ في الصور البعيدة أو المائلة أو ذات الانعكاس، لذلك تأكيد المستخدم ضروري.

ملاحظة أمنية قبل النشر:
عدّل إعداد CORS في backend/main.py ليسمح بعنوان موقعك فقط، ولا تترك allow_origins=["*"] في الإنتاج.
